# Renders

- `physics-analysis/` contains eight PNG plots generated by `simulation/eds_physics_analysis.py`.
- `reference/` contains three project figures covering Martian environmental risk, particle adhesion physics, and system architecture. These are image assets; proposal and other source documents are not included.

Only PNG renders are checked in; the script can also export PDF locally. The analysis plots visualize the archived model's assumptions and are not independently validated engineering predictions.
